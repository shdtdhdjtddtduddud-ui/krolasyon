# Krolasyon Orman Bekçisi Okçuluk Seti (Forge 1.20.1)

Kadim orman bekçilerinin yayı, oku ve sadağı. Tüm modeller prosedürel 3B ve animasyonlu.

**Orman Bekçisi Yayı**
- Taşlaşmış ahşaptan köşeli, dikenli kollar; altın ve koyu sargılar; sallanan turkuaz tüyler
- Çekme animasyonu: kollar bükülür, kiriş geri gelir, oka yerleşir
- 14 tikte tam gerilir (vanilya 20), %50 daha güçlü ve hızlı atış, 1200 dayanıklılık, yay büyüleri çalışır
- Tam gerilince **Rüzgar Oku**: kritik, 2 düşmanı deler
- Eğilerek tam gerilince **üçlü yaylım**
- Okları önce Orman Sadağından çeker (%25 ok tasarrufu), yoksa envanterdeki oklardan

**Orman Oku**: altın baklava uç, üç turkuaz tüy. Uçarken en yakın düşmana yönelir, ışıltılı iz bırakır, 3 temel hasar.

**Orman Sadağı**: yeşil deri, çapraz kayışlar, turkuaz taşlı altın plakalar. 256 ok taşır (demet gibi: ok
yığınını üzerine bırak / sağ tıkla çıkar). Envanterdeyken **sırtınızda görünür**, içindeki ok sayısına göre dolar.

**Edinme**
- Yay: ` DS` / `E S` / ` DS` (D koyu meşe kütüğü, S ip, E zümrüt) · konak %25, karakol %12
- Ok (8 adet): ` N ` / `LSL` / ` F ` (N altın parçacığı, S çubuk, L yaprak, F tüy) · orman tapınağı, zindan
- Sadak: `LEL` / `L L` / `LGL` (L deri, E zümrüt, G altın külçe) · orman tapınağı %25, karakol %15
